How Maintenance Mode Works

When Enabled:
  • Admins can still access admin panel
  • Admins can still perform actions
  • All audit logs are recorded
  • Users see maintenance message
  • Users cannot upload items
  • Users cannot create trades/orders
  • Users cannot browse marketplace (optional)
Use Cases:
  • Database maintenance or migration
  • System upgrades or deployments
  • Critical bug fixes
  • Security updates
  • Infrastructure scaling
Best Practices:
  • Set a clear message explaining the maintenance
  • Give users an estimated time
  • Provide contact info for urgent issues
  • Disable only when necessary
  • Re-enable as soon as possible
